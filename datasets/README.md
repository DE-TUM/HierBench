# Hierarchical benchmark data

Data files for the hierarchical taxonomy datasets and their predefined benchmark splits.
Generated by an export script — edit nothing by hand.

Flat layout — one folder per source taxonomy plus one sibling folder per predefined split.

Source files, per taxonomy (`nasa/`, `doid/`, `acmccm/`, `euroscivoc/`, `mesh/`):

- `dataset.tsv` — raw triples (`head \t relation \t tail`, labels).
- `metadata.tsv` — per-entity metadata (shared: the split datasets reuse it, not a copy).
- `closure.tsv` — the non-direct transitive closure of the hierarchy relation: every
  (ancestor, relation, descendant) pair implied by transitivity that is not a basic/direct edge,
  in canonical parent->child orientation, sorted. Lets the closure-based splits skip the
  transitive reduction and closure enumeration.

Predefined splits, one flat folder each, `{slug}-ancestor-descendant-closure{percent}/{train,valid,test}.tsv`
(e.g. `nasa-ancestor-descendant-closure0/`) — the frozen multi-hop transitive ancestor-descendant
split (`seed=42`, `eval_ratio=0.05`, the named `closure_ratio`). These files **already have the
transitive (non-direct) ancestor-descendant edges worked into the split**: `train.tsv` holds the
basic/direct edges (plus the folded-in closure fraction), `valid.tsv`/`test.tsv` hold disjoint 5%
portions of the remaining non-direct transitive closure (Ganea et al. 2018 §5; He et al. 2024 §4.1)
— no closure computation is needed to use them.

`wordnet-noun-{0,10,25,50,90}percent/{train,valid,test}.tsv` are the WordNet noun `maxn` splits of
Ganea et al. 2018 (https://github.com/dalab/hyperbolic_cones), mirrored verbatim.
